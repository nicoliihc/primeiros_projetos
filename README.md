# lopal_exercicios

Exercicios desenvolvidos na unidade curricular LOPAL (Logica de Programacao e Algoritmos) do curso tecnico de Desenvolvimento de Sistemas no SENAI.

## Descricao

Este projeto contem a solucao de exercicios praticados em sala de aula com o objetivo de fixar conceitos de logica computacional e estruturas fundamentais utilizando a linguagem Java.

## Tecnologias

- Java
- IntelliJ IDEA
- Git
